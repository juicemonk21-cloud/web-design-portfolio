# Aleksandr Bokhan — web design and development portfolio

Three independent concept projects with fictional brands and sample data:

- [Cala Selva](atelier/) — boutique hotel website
- [Hollow Form](commerce/) — interactive product storefront
- [Northline](crm/) — CRM dashboard with a local Python and SQLite demo

The published Northline site runs in browser storage mode. Its Python API is available for local demonstration by running `server.py` inside `crm/`.

These projects demonstrate design and development work. They are not client commissions. The storefront does not process payments, and the hotel site does not submit bookings.

# Aleksandr Bokhan — web design and development portfolio

Four independent concept projects with fictional brands and sample data:

- [Live portfolio](https://juicemonk21-cloud.github.io/web-design-portfolio/)
- [Nocte](https://juicemonk21-cloud.github.io/web-design-portfolio/restaurant/) — four-page restaurant website concept with an interactive table request demo
- [Cala Selva](https://juicemonk21-cloud.github.io/web-design-portfolio/atelier/) — three-page boutique hotel website concept
- [Hollow Form](https://juicemonk21-cloud.github.io/web-design-portfolio/commerce/) — interactive product storefront
- [Northline](https://juicemonk21-cloud.github.io/web-design-portfolio/crm/) — CRM dashboard with a local Python and SQLite demo

The published Northline site runs in browser storage mode. Its Python API is available for local demonstration by running `server.py` inside `crm/`.

These projects demonstrate design and development work. They are not client commissions. The restaurant's table request is stored in the visitor's browser for demonstration; it does not create a real reservation. The storefront does not process payments. The hotel site's inquiry form sends an email to the portfolio owner; it does not place a reservation.

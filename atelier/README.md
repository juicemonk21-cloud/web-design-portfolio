# Cala Selva — boutique coastal retreat concept

A fictional hospitality website created as a portfolio demonstration. The brand and room descriptions are sample content. Do not present it as commissioned client work.

## Features

- Responsive editorial layout with original imagery and local WebP assets
- Three connected pages: the house, suites, and the place
- Stay inquiry drawer with date and contact validation on every page
- FormSubmit delivery to the portfolio owner's work email
- Mobile navigation, scroll reveals, reduced-motion support, and visible focus states
- No framework or build step required

## Run locally

Serve this folder with `py -m http.server 8000` on Windows and open `http://localhost:8000`. The pages can also be viewed as local files, but FormSubmit requires an HTTP server for delivery.

The inquiry form sends details to the designer through FormSubmit; it does not create a reservation. The FormSubmit address was activated and tested on localhost. FormSubmit may request a fresh activation for the published GitHub Pages origin after deployment. Replace all fictional property information and connect the hotel's own email or booking service before use by a live property.

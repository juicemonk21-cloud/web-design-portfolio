# Cala Selva — boutique coastal retreat concept

A fictional hospitality website created as a portfolio demonstration. The brand, room descriptions, and stay planner are sample content. Do not present it as commissioned client work.

## Features

- Responsive editorial layout with original imagery and local WebP assets
- Room selector with keyboard-accessible tabs
- Stay-planning drawer with date validation and a clear preview state
- Mobile navigation, scroll reveals, reduced-motion support, and visible focus states
- No framework or build step required

## Run locally

Open `index.html` in a browser, or serve this folder with `py -m http.server 8000` on Windows and open `http://localhost:8000`.

## Portfolio notes

Suggested project title: **Cala Selva — Boutique Hotel Website Concept**

Suggested description: **Designed and built a responsive boutique hotel concept with an editorial visual system, room comparison, a stay-planning interaction, accessible navigation, and smooth motion. Created and optimized original visual assets for the experience.**

Images in `assets/` were generated for this concept and are local to the project. No external photos are used. The Google Fonts stylesheet is loaded from Google; the page falls back to system serif and sans-serif fonts if unavailable.

The booking drawer previews details locally and does not send or store a reservation. Replace all fictional property information and connect a real booking service before use by a live hotel.

Ready-to-use portfolio images are in `screenshots/`: full-page and first-screen captures at desktop and mobile widths.

# Hollow Form — commerce portfolio concept

A responsive product storefront for a fictional portable lamp brand. The page demonstrates visual direction, product storytelling, scene switching, and a working client-side bag drawer with quantity controls and keyboard support.

## Run

Open `index.html` in a browser, or serve this directory with any static file server. For example:

```sh
npx serve .
```

There is no build step or package installation.

## Scope

The brand, lamp, specifications, and pricing are illustrative. The bag is a frontend demonstration and checkout is intentionally unconnected. Replace these details and connect a commerce backend before any real sales use.

## Assets

The three lamp photographs in `assets/` were created for this concept and are included locally. The typeface is Archivo from Google Fonts, licensed under the SIL Open Font License. No third-party stock photography is used.
